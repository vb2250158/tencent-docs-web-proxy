# 验证记录

## 0.1.1

在 Windows、Node.js 24.15.0、Google Chrome 环境完成真实账号验收，使用自制的 10 秒英语合成音频，未使用私人录音。登录态保存在仓库外，Windows DPAPI 加密保存与重载成功。

- 客户端真实回读转写额度，通过临时 COS 授权完成上传和媒体时长识别，取得任务 ID 并查询到 `progress=100`、`errCode=0`。
- 通过本地 HTTP API 重新执行上传与转写，提交返回 `202`，随后查询到完成状态及 HTTPS 结果文档链接。
- 同一 HTTP `Idempotency-Key` 重放返回相同任务 ID；该轮额度总计只扣减原音频的 10 秒。
- 两次真实任务合计消耗 20 秒。通过腾讯文档官方 MCP 独立回读结果文档，核对 “Hello”、 “short transcription test”、 “audio upload”、 “task status”、 “final text” 五项内容，全文读取结束。
- `npm test`：25 项通过；`npm run check`：通过。依赖审计与暂存区安全筛查在发布时再次执行。

真实响应表明 COS 区域名没有必需的数字后缀，媒体时长字段可能是十进制字符串，结果文档链接可能省略协议。0.1.1 修正这三处，并增加回归测试。此前两次准备阶段失败均发生在转写提交之前；原测试请求身份经明确取证后继续使用，没有自动重发未知提交。

此验收覆盖短英语 WAV、单说话人和当前账号。长音频、视频、多语言、说话人分离及不同套餐尚未做真实账号验收。结果全文通过独立 MCP 核对；代理 API 本身仍返回文档链接，未实现 TXT/SRT 导出。

## 0.2.0

验证环境为 Windows、Node.js 24.15.0 和已登录的腾讯文档账号，全部输入使用自制 PDF、DOCX、XLSX、XMind、PNG、Markdown 与英语合成音频。

完成 33 项自动工具的实际文件或真实账号验收，逐项清单见 toolbox.md。本地验证检查页面顺序、旋转、可提取文字、中文文字叠加、PNG 尺寸、拼接像素和压缩格式。云端取得任务或结果文档，覆盖 PDF 转 Word/Excel/PPT、Office 转 PDF/图片、PDF/Office 压缩、图片 OCR、思维导图转换、AI 阅读及创作、收集表、网页剪存和音视频转写。

PPT 原生生成取得文件结果。早先官方 MCP 异步生成试验的会话随后返回 not_found，未将该试验计作成功；当前 PPT 路径使用网页原生大纲生成与文件创建。默认模板 29000 来自当前公开前端。Office 转图片验证发现编辑页 HTML 与实际 PDF 下载地址不同，修复为通过 drive 下载接口取得原文件后再渲染。

权益实测确认 PDF 转 Word、Excel、PPT 的 unlimit=true。数值 rest=1 作为接口占位保留，界面以“无限量”呈现。语音速记通过单数 right/get?id=25 回读，转写通过复数 rights/get 读取，二者余额一致，unlimit=false。语音速记新增 10 秒合成音频任务通过，按共用池扣减 10 秒。

3 项原生编辑流程和 7 项第三方插件提供入口、输入准备或元数据，最终编辑、授权与签署未完成自动验收。智能翻译的合成 PDF 导入返回 10321，保留原生上传入口与错误码。麦克风硬件、真实浏览器录音权限及实际录音尚待用户设备操作；音频上传与转写后端已实测。

WebGUI 的目录、额度、搜索、参数面板和无本地 token 登录由 DOM 行为测试覆盖。用户在应用浏览器查看了实际页面并反馈额度与登录交互，本轮按反馈移除 token 门槛并修正无限量显示。自动视觉巡检受 Work 的本地浏览器使用设置关闭所限，未声称完成该巡检。

恢复验证覆盖丢失响应后保留原请求、重启后标注未知写入、多个输入逐项处理、插件元数据失败仍可打开原生入口。Agent stdio 实际连接并列出 47 个工具。本地自动测试 48 项通过，JavaScript 语法检查通过，生产依赖审计为 0 个已知漏洞。服务与发布版本的回读以提交及 CI 回执为准。
